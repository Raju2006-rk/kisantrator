Mobile-first direct tractor marketplace connecting farmers in Nashik with local tractor owners with zero commission.

💡 Why was GitHub Pages showing 404?
GitHub Pages is a static file server that looks for an index.html. Because KisanTractor is a full-stack Next.js app with server-side API routes, dynamic cookies, and backend logic, it requires a Node.js server to run live.
